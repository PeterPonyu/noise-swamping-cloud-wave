The object

A wave is a listed set of model × layer × seed × quant cells. This repo stores the runner and the pulled arrays.

It does not redefine the noise-swamping gates. An 8B geometry cell from another direction is not an 8B noise-swamping anchor.

What is measured

  • Local curve readout: 9/9 cells, ρ = −0.900
  • Per-cell phase-1 tables in the quant-survival archive
  • Family means as reported on the noise-swamping site

Protocol

  • Launch only the listed wave cells.
  • Pull arrays into the quant-survival tree.
  • Rebuild the local readout on CPU. Do not silently add extra cells to the curve.

Measurements

Duty

Produce and archive the remote cells. The noise-swamping page states the object and the curve.

Non-goal

Not a second science object. Not a place to rewrite gates.

Open

The 8B noise-swamping anchor is not launched from this archive until its own receipt exists.
